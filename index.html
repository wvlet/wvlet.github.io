wvlet.org is home to two open-source projects: Wvlet, a query language you write in the order data flows, and Uni, the Scala 3 library that Wvlet itself is built on.

Wvlet

Flow-style query language

Start from a table and pipe it through operators. Run queries on Wvlet's own columnar engine, in-process on the JVM, Node.js, browsers, or as a native binary, or compile them to SQL for the warehouse your data lives in.

  • Wvlet engine
  • DuckDB
  • Trino
  • Snowflake
  • Hive

Uni

Essential Scala 3 utilities

One library for the whole stack: object wiring, logging, JSON and MessagePack, Rx, HTTP, RPC, MCP servers, web UI, and testing, with minimal dependencies. The Scala 3 successor of Airframe.

Wvlet

Write queries
in the order data flows

SQL's syntax order doesn't match how data moves through a query. Wvlet starts from from and reads top to bottom, so you can run any prefix of a query to check intermediate results.

  • Reusable and testableData models, functions, and inline debug and test steps.
  • A choice of enginesA built-in columnar engine, experimental GPU acceleration, or the SQL engine you already use.
  • Embed it anywherePython and TypeScript SDKs and a C-compatible native library.

revenue.wvwvlet
from orders
where o_orderdate >= '1997-01-01'
group by o_orderpriority
agg _.count as orders, o_totalprice.sum as revenue
order by revenue desc
limit 5

Uni

One Scala 3 library
for the whole stack

Uni gives Scala 3 applications the building blocks they need, with few transitive dependencies, and the same code runs on the JVM, Scala.js, and Scala Native.

  • Plain classes, wired togetherDesign connects services through their constructors and manages their lifecycles.
  • Codecs from case classesAdd derives Weaver to get JSON and MessagePack.
  • HTTP, RPC, and MCPClients and servers on every platform, typed RPC from Scala traits, and MCP servers for AI tools.
Get started with Uni →
Orders.scalascala 3
import wvlet.uni.design.Design
import wvlet.uni.log.LogSupport
import wvlet.uni.weaver.Weaver

case class Order(id: Long, region: String) derives Weaver

class OrderService extends LogSupport:
  def handle(json: String): Order =
    val order = Weaver.fromJson[Order](json)
    info(s"order ${order.id} from ${order.region}")
    order

Design.newDesign
  .bindSingleton[OrderService]
  .build[OrderService] { svc =>
    svc.handle("""{"id":1,"region":"asia"}""")
  }
